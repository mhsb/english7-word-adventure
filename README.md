# ماجرای کلمه‌ها — انگلیسی هفتم (Prospect 1)

اپ گیمیفیکیشن برای یادگیری واژگان کتاب انگلیسی پایه هفتم؛ مخصوص دانش‌آموزی که پایه‌ی ضعیف دارد: شنیدن، خواندن و نوشتنِ کلمه‌ها و عبارت‌های هر درس، با باغ گل، ستاره و مرور هوشمند. PWA و آفلاین.

## درس‌های موجود
- درس ۱ — My Name
- درس ۲ — My Classmates
- درس ۳ — My Age
- درس ۴ — My Family

(منبع واژگان: بخش‌های Conversation و Key Language هر درس و Photo Dictionary کتاب.)

## مسیر یادگیری هر کلمه (شیب آرام)
آموزش ← سؤال دوجوابیِ فوری ← خواندن ← جای خالی تدریجی با انتخاب (۱ حرف، دوباره ۱ حرف در جای دیگر، ۲ حرف، چند حرف، کل کلمه) ← تایپ تدریجی (حرف‌های جاافتاده) ← املای کامل.
عبارت‌های چندکلمه‌ای همین مسیر را با «کلمه» به‌جای «حرف» می‌روند. کلمه‌های بی‌تصویر با گزینه‌های ترجمه تمرین می‌شوند. مأموریت نیمه‌کاره ذخیره می‌شود و از همان‌جا ادامه پیدا می‌کند.

## افزودن درس جدید
فقط `lessons.js` را ویرایش کن: یک آبجکت جدید به `LESSONS` اضافه کن (نمونه‌اش درس‌های بالای همان فایل است).

## اجرا
فایل `index.html` را باز کن، یا با GitHub Pages منتشر کن (Settings → Pages → Branch: main، پوشه‌ی root).
